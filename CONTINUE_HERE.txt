## Quick Start
```bash
# Test Gemma 4
python run_cli.py test

# Analyze code (stdin)
python run_cli.py analyze --stdin --dimension bias << 'EOF'
# your code here
EOF

# Analyze file
python run_cli.py analyze path/to/file.py -d security
```
